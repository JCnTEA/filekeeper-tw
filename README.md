# 檔案管家（FileKeeper TW）

一套**完全繁體中文**、**零第三方依賴**的開源檔案管理器，使用 Python 標準庫的 tkinter 打造。
主打一件事：**把「刪除檔案」做得又快又安全** —— 預設丟進資源回收筒，真要永久刪除時必須再勾一次確認。

> 授權：MIT｜語言：Python 3.9 以上｜平台：Windows、macOS、Linux

---

## 功能特色

| 功能 | 說明 |
| --- | --- |
| 資料夾瀏覽 | 選擇任意資料夾、上一層、重新整理，清單即時更新 |
| 搜尋與篩選 | 依「檔名關鍵字」搜尋，並可依圖片／文件／音訊／影片／壓縮檔／程式碼／執行檔分類篩選 |
| 欄位排序 | 點擊「名稱／類型／大小／修改時間」欄位標題即可排序，再點一次反向排序 |
| 批次刪除 | 支援 Ctrl／Shift 多選，一次刪除多個檔案並統計釋放空間 |
| 兩種刪除模式 | ① 移到資源回收筒（可還原，預設）② 永久刪除（需勾選確認） |
| 系統保護 | 系統目錄、程式安裝目錄、磁碟根目錄下的檔案一律拒絕刪除 |
| 快速操作 | 雙擊開啟檔案、右鍵選單（開啟／顯示所在資料夾／複製路徑／刪除） |
| 繁中介面 | 介面、程式註解、文件全部為繁體中文，並自動選用正黑體等中文字型 |

## 系統需求

- Python 3.9 以上（Windows 安裝時請勾選「Add python.exe to PATH」）
- 不需要 `pip install` 任何套件；tkinter 屬於 Python 標準庫
  - 若使用 Linux 且缺少 tkinter，請安裝 `python3-tk`

## 快速開始

### Windows（最省事）

1. 下載整個專案資料夾。
2. 雙擊 **`啟動.bat`**。

> `啟動.bat` 會優先使用系統安裝的 Python（透過 `py` 啟動器）；若雙擊沒有反應，
> 請開命令提示字元執行 `py filekeeper.py` 查看錯誤訊息。

### 命令列（全平台）

```bash
git clone https://github.com/<你的帳號>/filekeeper-tw.git
cd filekeeper-tw
python filekeeper.py
```

## 使用說明

1. 按 **「選擇資料夾」** 指定要管理的目錄（預設開啟使用者家目錄）。
2. 用 **搜尋檔名** 與 **類型** 下拉選單縮小範圍。
3. 在清單中選取檔案（可多選），按 **「刪除選取檔案」**。
4. 在確認視窗中選擇刪除方式：
   - **移到資源回收筒（可還原）**：等同在檔案總管按 Delete，事後可從回收筒救回。
   - **永久刪除（無法復原）**：需勾選「我了解永久刪除後無法復原」才會解鎖按鈕。
5. 刪除完成後，狀態列會顯示「已刪除 N 個檔案，釋放 X」；若部分檔案失敗或受保護，會另外跳出說明。

### 右鍵選單

| 選項 | 行為 |
| --- | --- |
| 開啟檔案 | 以系統預設程式開啟 |
| 開啟所在資料夾 | Windows 在檔案總管中選取該檔；macOS 用 Finder 顯示 |
| 複製完整路徑 | 複製到剪貼簿（多選時一行一筆） |
| 刪除選取檔案… | 進入刪除確認流程 |

## 刪除功能的安全設計

刪除是**唯一會造成資料損失**的操作，因此本專案的設計原則是「預設安全、要破壞就多按一次」：

1. **預設走資源回收筒**：Windows 透過 Shell 的 `SHFileOperationW`（`FOF_ALLOWUNDO`）實作，
   與檔案總管完全相同的還原機制。
2. **永久刪除需雙重確認**：必須先切換到「永久刪除」，再勾選確認框，按鈕才會變為可用。
3. **系統路徑保護**：`protected_reason()` 會擋下系統目錄（`%SystemRoot%`、`%ProgramFiles%`、
   `%ProgramData%` 等）與磁碟根目錄下的檔案。
4. **只刪檔案、不刪資料夾**：掃描時刻意忽略子資料夾與符號連結，避免誤刪整個目錄。
5. **逐筆回報**：成功、失敗（例如檔案被其他程式占用）、略過（受保護）三種結果都會列出來。
6. **非 Windows 平台的替代方案**：沒有統一回收筒 API，改為搬進 `~/.filekeeper-trash`，
   檔案仍可手動救回。

## 專案結構

```
filekeeper-tw/
├── filekeeper.py            # 程式入口
├── filekeeper/              # 套件本體
│   ├── __init__.py          # 版本資訊
│   ├── core.py              # 掃描資料夾、刪除檔案、路徑保護

│   └── ui.py                # tkinter 介面與刪除確認對話框
├── tests/
│   └── test_core.py         # 核心邏輯單元測試
├── .github/
│   └── workflows/
│       └── tests.yml        # 推送後自動跑測試（Windows／Linux × Python 3.9／3.13）
├── 啟動.bat                 # Windows 雙擊啟動
├── README.md
├── CHANGELOG.md
├── LICENSE
├── LICENSE-zh-TW.md          # MIT 授權繁體中文譯本
└── .gitignore
```
